# dice-trip

フリーきっぷの範囲内から6つの行先候補を生成し，サイコロで次の目的地を決める静的Webアプリです．

## 対応きっぷ

- 都区内パス
- 東京メトロ24時間券
- 東京メトロ・都営地下鉄共通1日乗車券
- 東京フリーきっぷ
- のんびりホリデーSuicaパス
- 休日おでかけパス

## 使い方

1. フリーきっぷを選ぶ
2. 現在地を入力する
3. 6択を生成する
4. サイコロを振る
5. 出た駅へ移動する
6. 到着後に「この駅に到着」を押して次の6択へ進む

時刻表，所要時間，帰宅可否，運休情報は判定しません．実際の移動前に各事業者の運行情報を確認してください．
